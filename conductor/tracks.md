## Backlog
- [ ] **Feature: User-Authored Layers, Saved Workspaces, Route Bookmarks & Filter Presets (`FS-002`, `FS-015`)** — Support creating, naming (e.g. *"Outer Colony Reach"*), saving, and importing/exporting custom user data layers (`kind: 'custom-user'`), personal lore annotations, bookmarked route trajectories, and reusable search/intent filter presets.
- [ ] **Feature: Local Night-Sky View to 3D Third-Person Projection (`FS-004`)** — Enter Earth location (lat/long or place) and time to view the local 2D night-sky dome, select visible stars, and pull out to a third-person 3D galactic projection to inspect their true 3D spatial depth.
- [ ] **Feature: Adaptive Multi-Tier Search Strategy & Dynamic 3D Sector Streaming (`FS-006`)** — Progressive client-side loading across `core.json` and `full.json` (zero-result escalation, background pre-warming, device/network tiering) paired with view-frustum/distance-gated streaming of 25-pc cubic sectors (`public/data/systems/sector_*.json`) and floating-origin shifting.
- [ ] **Feature: SEO, Structured Metadata & Curated Shortlink Landing URLs (`/go/<slug>`, `FS-007`, `FS-008`)** — Dynamic per-route `<title>` / Open Graph metadata, `sitemap.xml` / JSON-LD structured data, and memorable entry-point URLs (`/go/hail-mary`, `/go/dune`, `/go/trappist`, `/go/voyager`) resolving to pre-configured camera framing, active layers, and routes.
- [ ] **Feature: GitHub Feature Requests & Bug Reports Integration (`FS-009`)** — Structured `.github/ISSUE_TEMPLATE/` forms and an in-app feedback action that opens pre-populated GitHub Issues with current URL/view/entity context.
- [ ] **Feature: 3D Guide Interior Cross-Section Cutaways & Comparative 3D Meshes (`FS-011`)** — WebGL/R3F edge-truncated 3D spheres with interior cross-section cutaway shaders and comparative Earth/Sol reference meshes inside the `/guide/*` 3D preview slots (`data-testid="guide-3d-preview"`, `data-testid="metric-comparative-3d"`).
- [ ] **Feature: Choreographed 3D Camera Transitions, Search Framing & Independent Center/Focus State (`FS-003`, `FS-012`, `FS-013`)** — Smooth 3D camera fly/zoom choreography across views (`Galaxy` $\leftrightarrow$ `System` $\leftrightarrow$ `Planet`) and intra-view state changes with HUD panel retraction/snap-back (`FS-012`), multi-result galactic search framing with Solar System single-result exception (`FS-003`), and independent camera `center` vs. entity `focused` state with conditional `Centre` CTA visibility (`FS-013`). *Cross-referenced across 6 coupled tracks: [Interaction Controls](./tracks/interaction-controls_20261010/spec.md), [Minimap & Scene Transitions](./tracks/minimap-scene-transitions_20261010/spec.md), [3D Engine Implementation](./tracks/3d-engine-implementation_20260929/spec.md), [Console UI Shell](./tracks/console-ui-shell_20261004/spec.md), [Telemetry Container & Dossiers](./tracks/telemetry-container_20261004/spec.md), and [Search & Discovery UI Surfaces](./tracks/search-discovery_20261004/spec.md).*
- [ ] **Feature: Multi-Leg Route Networks, Epoch Orbital Timing & Solar Conjunction Blackouts (`FS-014`, `FS-017`)** — Arbitrary-origin multi-stop route networks (`?route=a,b,c`), pairwise/cumulative comms latency matrix, and speculative propulsion tiers (`FS-014`), paired with `<ControlBar />` epoch-driven Keplerian orbital separation (`AU` / light-minutes between conjunction and opposition) and solar conjunction coronal exclusion blackout warnings (`FS-017`).
- [ ] **Feature: Volumetric Interstellar Clouds & Galactic Structures on the Galaxy Map (`FS-016`)** — Render volumetric 3D interstellar media (CLIC clouds: *LIC*, *G-Cloud*, *Blue Cloud*, *Aquilae*, *Mic*, *Leo*, *Dor*, *Eri*, *Vela*; *Local Bubble*; and nearby molecular/dark cloud complexes: *Rho Ophiuchi*, *Taurus*, *Coalsack*, *Lupus*, *Chamaeleon*, *Pipe*) via micro-dot point-density stippling and planar survey cross-hatching on `GalaxyView` (`GalaxyScene`), evaluate 3D sphere–sphere intersection against the Cartographic Instrument aperture ($\text{distance}(\text{centre}, \text{cloud}) \le R_{\text{aperture}} + R_{\text{cloud}}$), and surface active/intersecting clouds and structures in `<BodiesPanel scope="galaxy" />`.
- [ ] **Feature: 3D Cartography & Visual Language Refinements** — High-fidelity procedural/photographic celestial & planetary textures with multi-scale LOD, finessed Keplerian orbit line styling (periapsis/apoapsis ticks, ascending/descending nodes), Layer 3 typographic offset geometry, multi-tier reticle collision priority hierarchy, kinematic velocity vector terminus calibration, and significance-gated toponymic filtering.
- [ ] **Feature: Keyboard Shortcut Modal, Command Palette, System Settings & Observability** — Accessible keymap cheat-sheet modal, production `Cmd+K` / `/` command palette, System Settings drawer (performance, audio/SFX, units, Light/Dark theme), and strongly typed interaction/WebGL performance analytics.
